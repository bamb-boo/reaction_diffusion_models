# Turing Patterns
In 1952, Alan Turing published a paper called the ["Chemical Basis of Morphogenesis"](https://www.dna.caltech.edu/courses/cs191/paperscs191/turing.pdf). In it, he described how varied patterns in animals could form from simple interactions between chemicals. It contained a set of Partial-Differential-Equations (PDEs) which modelled the pattern formation. 
##### Inspiration
I've always been interested in math. When an opportunity popped up at my school to research about the formation of *random* patterns in animals, I was instantly addicted to the idea of Turing patterns. This idea is also incredibly cool, and revolutionary, since it demonstrated that heterogeneous patterns can be formed from an homogeneous state *using diffusion*, which usually makes interactions simpler.
